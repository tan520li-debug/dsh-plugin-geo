## 豆包应用市场（主路径）

- 入口：豆包开放平台 → **商店插件**（不是飞书企业自建应用）。
- 包：`doubao/plugin.json`、`doubao/mcp.json`、`doubao/skills/` 打成 zip，根目录即这三类，不要多套一层文件夹。
- MCP 规范：远程 HTTPS、`mcpServers` 与 `plugin.json` 里 `extensions.com.doubao.mcpServers` 键一致；工具由服务端 `tools/list` 提供。
- 连接器 / 技能：见 [MCP Server 接入](https://open.doubao.com/document/plugin-docs-center/build/mcp-server-development/plugin-development-spec/mcp-server-development)、[Skills 规范](https://open.doubao.com/document/plugin-docs-center/01-skills/integration-and-development-spec)、[豆包工作自定义连接器](https://www.doubao.com/work/docs/zh-cn/articles/705018132598-plugins)（HTTP + URL，非商店上架）。

**账号状态**：须本人登录 [open.doubao.com](https://open.doubao.com) 查看（开发者身份、商店插件是否已创建、审核状态）。助手无法读取你的登录态。
