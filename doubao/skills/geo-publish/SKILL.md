# 本机发布

默认不发布。对方没有明确说「一键发布」，就不要发布。

1. 只发这一次点了名的平台，并且稿子已经在本地文件里。
2. 小红书只把文案留在本地，不代填。
3. 发布在这台电脑上完成，不把稿子送进界问队列。
4. 这台电脑没有发布程序，或结果里没有「已在侧边栏打开」，就停。其他失败只说「这次没有完成」。
