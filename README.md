# GEO优化

把界问的 GEO 接到 DSH 或豆包。公司资料确认后可以保存，并生标题、生文。

服务地址：`https://geo.wenjjiegeo.cn/api/tlrai/mcp`

工具：

- `save_company`：保存对方确认过的公司资料
- `generate_title`：生标题
- `generate_article`：生文

没有公司资料时不要生标题或生文。不要编造客户、数字、效果和资质。提示词在服务端，不在这个仓库里。

在 2026-12-19 23:59:59 之前可以不带口令连接。这段时间不带口令时，公司资料存在服务端的同一份里。

## DSH

插件页选择「安装第三方插件」，填这个仓库的 Git 地址。装好后新开一轮对话即可使用。

## 豆包

自定义连接器选 HTTP，地址填上面的服务地址。请求头在免费期内留空。

也可以把 `doubao` 目录打成 zip 后，在技能页上传。zip 里要有 `plugin.json`、`mcp.json` 和 `skills`。

## 发布

发布不在这个连接里。对方明确说「一键发布」之后，才在他自己的电脑上发布。小红书不代填，稿子不送进界问队列。
